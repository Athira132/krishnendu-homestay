3. FASTEST DEPLOYMENT METHOD (Hostinger hPanel File Manager)
--------------------------------------------------------------------------------
Follow these simple steps:

STEP 1: Log in to Hostinger hPanel
  - Go to https://hpanel.hostinger.com and log in with your credentials.

STEP 2: Open File Manager
  - Go to "Websites" in the top navigation.
  - Click "Manage" next to your domain name.
  - In the left sidebar or under the "Files" section, click "File Manager".
  - Choose "Access files of [your domain]".

STEP 3: Navigate to public_html
  - Double-click to open the `public_html` folder.
  - If you see a default Hostinger file (like `default.php`), delete it.

STEP 4: Upload the ZIP File
  - In the top-right toolbar of File Manager, click the "Upload" icon (arrow pointing up).
  - Select "File" and choose `krishnendu-homestay-hostinger.zip` from your computer.
  - Wait for the upload progress bar to reach 100%.

STEP 5: Extract the ZIP
  - Right-click `krishnendu-homestay-hostinger.zip` in File Manager.
  - Select "Extract".
  - When asked for folder destination, leave it blank or enter `.` (dot) to extract 
    directly into `public_html`.
  - Click "Extract".

STEP 6: Verify File Placement
  - Make sure `index.html` and `.htaccess` are directly inside `public_html`!
    (Path should be: public_html/index.html, NOT public_html/dist/index.html).
  - If they were extracted into a subfolder, select all files inside that subfolder, 
    click "Move", and select `public_html` as destination.

STEP 7: Clean Up
  - Delete `krishnendu-homestay-hostinger.zip` from File Manager to save disk space.

If you prefer using FTP:

   `public_html`.

5. THE CRUCIAL .htaccess FILE & ROUTING EXPLANATION
--------------------------------------------------------------------------------
WHY .htaccess IS INCLUDED:
Because this website uses client-side routing (React Router), URLs look like:
  - https://yourdomain.com/properties
  - https://yourdomain.com/properties/krishnendu-homestay
  - https://yourdomain.com/properties/krishnendhu-residency
  - https://yourdomain.com/properties/sivaranjini-tourist-home
  - https://yourdomain.com/discover-guruvayur
  - https://yourdomain.com/about
  - https://yourdomain.com/gallery
  - https://yourdomain.com/contact

When a visitor refreshes any of these sub-pages or clicks a direct link, standard 
web servers (Apache / LiteSpeed) look for physical folders on the disk. Without 
our `.htaccess` file, the server would return a "404 Not Found" error.

Our pre-configured `.htaccess` file tells the server:
"If the visitor requests a URL that is not an actual image or file, serve index.html 
and let React Router display the correct page smoothly."

NOTE ABOUT HIDDEN FILES:
Files starting with a dot (like `.htaccess`) are considered hidden in Linux.
If you do not see `.htaccess` in Hostinger File Manager:
- Click the Settings (gear icon) in the top-right corner of File Manager.
- Check "Show hidden files (dotfiles)".
- Click Save.

6. DOMAIN & SSL CONFIGURATION
--------------------------------------------------------------------------------
1. Pointing your Domain:
   - If your domain is registered with Hostinger, it is connected automatically.
   - If your domain is registered with GoDaddy, Namecheap, Google Domains, etc.:
     Point your domain's Nameservers to Hostinger:
     NS1: ns1.dns-parking.com
     NS2: ns2.dns-parking.com
     (Or use the Hostinger A Record IP shown in your hPanel dashboard).

2. Activating Free SSL (HTTPS):
   - In Hostinger hPanel, go to "Security" -> "SSL".
   - Click "Install SSL" on your domain.
   - Go to "Websites" -> "Dashboard" -> toggle ON "Force HTTPS".
   - This ensures all visitors automatically browse securely over https://.

7. SITEMAP & ROBOTS.TXT CUSTOMIZATION
--------------------------------------------------------------------------------
In the root of the website package, we have included:
- `robots.txt`
- `sitemap.xml`

Both files contain the placeholder `YOUR_DOMAIN.COM`.
Once your official domain is connected (for example: `krishnendhuhomestay.com`):
1. Open `sitemap.xml` in Hostinger File Manager (Right-click -> Edit).
2. Use Find & Replace to replace `YOUR_DOMAIN.COM` with your actual domain name 
   (e.g., `krishnendhuhomestay.com`).
3. Open `robots.txt` and replace `YOUR_DOMAIN.COM` with your actual domain name.
4. Save both files.
5. (Optional) Submit `https://yourdomain.com/sitemap.xml` to Google Search Console 
   for indexing.
