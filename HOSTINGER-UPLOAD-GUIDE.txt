3. FASTEST DEPLOYMENT METHOD (Hostinger hPanel File Manager)
--------------------------------------------------------------------------------
Follow these simple steps:

STEP 1: Log in to Hostinger hPanel
  - Go to https://hpanel.hostinger.com and log in with your credentials.

STEP 2: Open File Manager
  - Go to Websites in the top navigation.
  - Click Manage next to your domain name.
  - In the left sidebar or under the Files section, click File Manager.
  - Choose Access files of [your domain].

STEP 3: Navigate to public_html
  - Double-click to open the public_html folder.
  - If you see a default Hostinger file (like default.php), delete it.

STEP 4: Upload the ZIP File
  - In the top-right toolbar of File Manager, click the Upload icon (arrow pointing up).
  - Select File and choose guruvayur-hostinger.zip from your computer.
  - Wait for the upload progress bar to reach 100%.

STEP 5: Extract the ZIP
  - Right-click guruvayur-hostinger.zip in File Manager.
  - Select Extract.
  - When asked for folder destination, specify /public_html (or .) to extract 
    directly into public_html.
  - Click Extract.

STEP 6: Verify File Placement
  - Make sure index.html and .htaccess are directly inside public_html!
    (Path should be: public_html/index.html, NOT public_html/guruvayur/index.html).
  - If they were extracted into a subfolder, select all files inside that subfolder, 
    click Move, and select public_html as destination.

STEP 7: Clean Up
  - Delete guruvayur-hostinger.zip from File Manager to save disk space.

4. ALTERNATIVE DEPLOYMENT METHOD (FTP / FileZilla)
--------------------------------------------------------------------------------
If you prefer using FTP instead of File Manager:
1. In hPanel, go to Files -> FTP Accounts to find your FTP host, username, and port (usually 21).
2. Open FileZilla (or WinSCP).
3. Connect using your FTP credentials.
4. On the Remote side, navigate into the public_html directory.
5. On the Local side, open the guruvayur folder.
6. Select ALL files and folders inside guruvayur (including .htaccess) and upload them into public_html.
7. Wait for all files to transfer.

5. THE CRUCIAL .htaccess FILE & ROUTING EXPLANATION
--------------------------------------------------------------------------------
This website is a Single Page Application (SPA) using client-side routing.
When a visitor visits:
  - https://yourdomain.com/properties/krishnendhu-residency
  - https://yourdomain.com/about
  - https://yourdomain.com/contact
or presses F5 (Refresh) on any subpage, Apache / LiteSpeed must route the request 
to index.html instead of giving a 404 Not Found error.

The included .htaccess file handles this automatically:

  <IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteBase /
    RewriteRule ^index\.html$ - [L]
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteRule . /index.html [L]
  </IfModule>

Additionally, .htaccess includes:
- Gzip/Deflate compression for ultra-fast load times.
- Browser cache headers (1 year for images/fonts, 1 month for CSS/JS).
- Security headers (X-Frame-Options, X-Content-Type-Options).

NOTE: In Hostinger File Manager, dotfiles (files starting with a dot like .htaccess) 
might be hidden by default. Click the Settings icon (gear) in the bottom-left of 
File Manager and make sure Show hidden files is enabled.

6. DOMAIN & SSL CONFIGURATION
--------------------------------------------------------------------------------
1. Connect Your Domain:
   - If your domain was purchased from Hostinger, it points automatically.
   - If purchased elsewhere (GoDaddy, Namecheap, etc.), update your domain's 
     Nameservers to Hostinger:
       ns1.dns-parking.com
       ns2.dns-parking.com
     OR point an A Record (@) to your Hostinger server IP address.

2. Enable Free Let's Encrypt SSL:
   - In hPanel, navigate to Security -> SSL.
   - Activate the free Lifetime SSL Certificate.
   - Toggle Enforce HTTPS ON so all traffic is secure.

7. SITEMAP & ROBOTS.TXT CUSTOMIZATION
--------------------------------------------------------------------------------
Once your live domain is active:
1. Open public_html/sitemap.xml in Hostinger File Manager (double-click to edit).
2. Replace all instances of https://YOUR_DOMAIN.COM with your real domain:
   For example: https://krishnendhuhomestay.com
3. Save the file.
4. Open public_html/robots.txt and replace https://YOUR_DOMAIN.COM/sitemap.xml
   with your actual URL.
5. Save the file.
